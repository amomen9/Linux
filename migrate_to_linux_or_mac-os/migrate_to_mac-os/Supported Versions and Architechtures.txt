This file is generated by run_project.ps1 by scanning the install descriptors
in documents/B_applications.json, together with the macOS release and CPU
architecture matrix the generated installer detects at runtime.

The generated installer in "Execute on macOS!/" is UNIVERSAL: ONE script set
runs on every macOS version and on both CPU architectures.  At start-up it
reads the release from sw_vers and the architecture from uname -m (plus
sysctl.proc_translated, so a Rosetta shell on an Apple Silicon Mac is still
recognised as arm64) and dispatches accordingly.

Application delivery is CASK-FIRST (a Homebrew Cask token is identical on
every macOS version and on both architectures -- Homebrew picks the matching
build itself).  Homebrew formulae cover CLI/developer tools, the Mac App
Store (mas) covers Store-only apps, and MacPorts is honoured when it is the
package manager the machine actually has.
